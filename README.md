"A blockchain project: A decentralized skill verification and bounty platform where users can create skill-based challenges (coding problems, design tasks, writing assignments) and stake STX tokens as rewards. Other users can submit solutions, and the community votes on the best submissions. Winners receive the staked tokens plus reputation NFTs that serve as verifiable skill certificates. The platform includes features for challenge creation, solution submission, time-based voting periods, automatic reward distribution, and a reputation system that tracks users' expertise across different skill categories. This creates a trustless way to verify skills and earn tokens while building a decentralized talent marketplace."
